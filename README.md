# Pinkongpicture

面向品控员的产品包装图片识别与 Excel 录入项目。

## 本地测试版

已实现本机浏览器工作台、PaddleOCR CPU 识别、七字段复核、产品档案、来料版本、图片分组、区域纠错样本与可配置 Excel 模板导出。

真实包装照片和已有 Excel 模板尚未提供，业务识别效果与实际模板版式仍待验收。软件流程测试使用合成资料，不能代替这两项验收。

本机已准备虚拟环境与模型，在项目目录启动：

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。安装、字段来源、模板设置、测试与数据保存方式见 [本地试用说明](docs/LOCAL_TEST_GUIDE.md)。

需求和阶段安排见 [产品需求文档](docs/PRD.md) 与 [开发计划](docs/superpowers/plans/2026-10-13-local-cpu-mvp.md)。

## 首期范围

- 基于 PaddleOCR，先在单台电脑上使用 CPU 测试。
- 导入手机拍摄的包装照片，自动建议分组，由人员检查调整。
- 提取产品名称、规格、生产厂商、生产地址、批号、生产日期和保质期。
- 人工复核后保存来料记录，并记录录入时间和操作人。
- 维护产品档案，使用历史资料辅助校对，保存有图片依据的纠错样本。
- 按现有 Excel 模板导出确认后的记录。

企业服务器、厂外访问、多人权限及模型训练留到后续阶段。

## 数据管理

包装原图、训练样本、模型权重、本地数据库和导出表格不提交到 Git。
默认业务数据保存在 `data/`，模型保存在 `models/`，导出文件保存在 `data/exports/`。测试资料位于 `.cache/`，与默认业务数据分开。
